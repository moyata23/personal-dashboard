Fighting Game Training App

Project notes • Website first, apps later

Free
See the move, not just the notation.

A move animation database — short looping clips of what a move actually looks like, tied to its string. Hear “1, 1, 2” in Tekken, see the animation, and it clicks.

🌐

Website first

Launch on the web so anyone can jump in fast. iOS / Android apps come later, once the core feels right. Free for users.

🎮

Multi-game, per-game pages

Game selector up top, then a dedicated page per game and character. Built to grow game by game without getting messy.

🧠

Teaches what games don't explain

Neutral, frame traps, whose turn it is — the concepts you normally only pick up from other players, explained plainly.

🎞️

Animation database + frame data later

Clips hosted on the site to start. Later: overlays that use the clip itself — e.g. tint red when a move is negative, with the number on it.

👥

Community-powered

Bug reporting to track issues, plus tech submissions — players submit tech for their game / character and it gets aggregated for everyone.

Money — clean first

No ads at launch. If ads ever come to cover costs, they have to be fighting-game relevant only:

  • Fight sticks, arcade sticks, leverless controllers, and parts
  • Possibly via Google AdSense with tight targeting
  • No random mobile-game ads — if it wouldn't help a player at the setup, it doesn't belong
